Projeto do curso de Desenvolvimento de sistemas, turma 231:

O projeto Sabor & Clic foi concebido para estruturar o núcleo tecnológico de
uma dark kitchen, integrando a gestão de espaços gastronômicos, o controle de
fichas técnicas e o fluxo de pedidos. Após a etapa inicial de planejamento conceitual
e prototipagem, o projeto avança para sua fase de implementação avançada e
consolidação arquitetural.

Nesta fase atual, o foco se direciona para a concretização do sistema por
meio do código funcional e integrado, a interface em HTML e CSS ganha vida com a
reestruturação do Front-end em JavaScript sob a Programação Orientada a Objetos,
garantindo o encapsulamento e a comunicação assíncrona com o back-end.

Simultaneamente, a camada de serviços em Python com o framework Flask
passa a gerenciar rotas robustas, sessões, cookies e middlewares de autenticação,
conectando de forma centralizada a um Banco de Dados Relacional. Para assegurar
a automação das regras de negócio e a integridade transacional, foram
implementadas triggers para baixa automática de estoque. Desse modo, o sistema
evolui de um modelo planejado para um ecossistema web funcional, modular e
seguro, preparado para atender plenamente aos requisitos operacionais dos
administradores, clientes e cozinheiros.

Para rodar:

- Instalar Flask
- Instalar dotenv dentro do ambiente virtual com pip install python-dotenv
- Crie o banco de dados com python app/iniciar_db.py
- Inicie o servidor com python run.py
